# Exchanges

We do not offer direct exchanges, including exchanges for a different size or color.

If you need a different size or color, return the original item following the return policy (30 days, never used, original packaging, tags attached) and place a new order for the item you want. The refund for the returned item is issued to your original payment method.

To make sure the item you want is still available, we recommend placing the new order right away rather than waiting for the refund.

If you received the wrong item or a damaged item, do not use this process. Report it under the damaged or defective items policy and we will send a replacement.
