# Order Changes and Cancellation

## Cancelling an order

You can cancel an order until it ships. Orders usually ship within 1 business day, so please cancel as soon as possible.

To cancel, open the order under **Orders** in your account and choose **Cancel order**. If the button is no longer shown, the order has already shipped and cannot be cancelled. You can return it after delivery following the return policy.

Refunds for cancelled orders go to the original payment method.

## Changing an order

Items, quantities and the shipping address can be changed only before the order ships. We cannot add items to an order that has already been placed; please place a separate order instead.

## Adding a promo code after ordering

Promo codes must be entered at checkout. They cannot be applied to an order after it has been placed, and we do not refund the difference if you forgot to enter a code.
